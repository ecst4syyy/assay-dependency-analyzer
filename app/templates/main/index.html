Is that package real, and is it safe?

AI coding assistants sometimes suggest packages that do not exist. If an attacker registers one of those invented names, anyone who copies the install command gets the attacker's code. This is called slopsquatting.

Paste AI-generated code or upload a requirements.txt or package.json. Assay checks each PyPI or npm package against the public registries and vulnerability databases, then explains every verdict.

  • Does the package exist?
  • Is it brand new, rarely downloaded, or one character away from a popular name?
  • Does it have known vulnerabilities, and are they being exploited (EPSS, CISA KEV)?

Assay reads metadata only. It never downloads, installs or runs a package.
